# OpenCode Spend v1.1.7

Мониторинг расходов и активности opencode: приложение на ПК собирает данные, а на
сервере работает веб-панель с аккаунтами. Траты, лимиты Go, платежи и живые
сессии с фазами — всё в одном месте.

### 🆕 Что нового в v1.1.7

- **Честные формулировки подключения.** По правилу «один аккаунт — один компьютер» подключение
  нового ПК заменяет прежний. Кнопка теперь называется «Подключить ПК», а на странице с кодом
  появляется предупреждение, что предыдущий компьютер отключится.

### 🆕 Что нового в v1.1.6

- **Код подключения ПК доступен всегда.** Раньше экран с кодом показывался только пока не
  подключён ни один компьютер, поэтому привязать второй ПК было нельзя. Теперь есть страница
  `/pair`, а в диалоге «Управление соединением» — кнопка «Подключить ещё один ПК».

### 🆕 Что нового в v1.1.5

- **Сессии со всех запущенных серверов opencode.** Если opencode запущен несколько раз (разные
  проекты, разные порты), панель теперь собирает чаты со всех серверов в одно дерево, а не
  показывает только первый попавшийся. Активность и остановка сессий работают для каждого сервера
  отдельно.

### 🆕 Что нового в v1.1.4

- **Документация на двух языках.** README теперь есть на английском (`README.md`) и русском
  (`README.ru.md`), со скриншотами десктопного, мобильного и планшетного вида.
- **Убрана карточка «Чаты — реальная стоимость»** — она дублировала данные других разделов.

### 🆕 Что нового в v1.1.3

- **Честное отслеживание активных чатов.** Активность больше не рисуется по эвристикам и
  таймерам: состояние берётся из реального статуса локального сервера opencode
  (`/session/status` с указанием каталога сессии). Убраны эмуляция и гистерезис.
- **Субагенты поднимают родителя.** Если работает дочерняя сессия, родительский чат тоже
  показывается активным.
- **Фазы сведены к честным:** работает / повтор / завершена.
- **Индикатор состояния на аватаре профиля.** Вместо текста статуса в шапке — плавно
  переливающаяся обводка: зелёная (онлайн), красная (оффлайн), синяя (подключён к серверу).
  При наведении — подсказка с состоянием и временем последней синхронизации.
- **Кнопки шапки выровнены по высоте**, текст статуса из шапки убран.

### 🆕 Что нового в v1.1.2

- **Исправлена главная причина «слетающего» пароля opencode.** Чтение окружения процесса
  было сломано (PEB читался двойным разыменованием), поэтому `OPENCODE_SERVER_PASSWORD`
  не находился вообще — панель показывала статус «доступен», но сессии не приходили.
  Теперь пароль читается корректно.
- **Пароль привязан к порту.** Пароль берётся у того процесса opencode, который слушает
  найденный порт (раньше — у произвольного из нескольких запущенных). Все запросы
  используют пароль, найденный вместе с портом.
- **Шапка больше не разъезжается.** При изменении ширины окна кнопки перемешивались и
  выстраивались в несколько строк. Теперь шапка всегда в одну строку: на средних экранах
  кнопки уходят в выпадающее меню, на широких остаются на месте.
- **Чистка кода.** Удалён неиспользуемый код, доступ к файлам состояния защищён блокировками,
  исправлено падение при отсутствии ключа `budget` в конфиге, добавлено логирование в местах,
  где исключения молча глотались. Сборка теперь без предупреждений.

### 🆕 Что нового в v1.1.1

- **Исправлен подхват пароля локального сервера opencode.** Раньше пароль искался один раз
  при старте приложения: если opencode запускался позже (автологин при перезапуске приложения,
  перезагрузка компьютера), панель оставалась без данных до ручного входа. Теперь поиск
  повторяется, пока пароль не найден, сбрасывается при отказе авторизации (401) и
  переискивает порт opencode, если тот перезапустился на другом порту.

### 🆕 Что нового в v1.1.0

- **Английский интерфейс.** Панель и страницы входа работают на русском и английском.
  Язык определяется автоматически по языку браузера, переключается кнопкой `EN`/`RU` в шапке.
  Страницы входа и подключения ПК тоже отдаются на языке браузера.
- **Мобильная версия.** На экранах уже планшета кнопки шапки собираются в выпадающее меню,
  скрывается имя пользователя, диалоги открываются как нижние панели, поправлены таблицы,
  графики и отступы под безопасные зоны экрана.

### 🚀 Быстрый старт

**ПК.** Распакуйте архив, запустите `OpenCodeSpend.exe`, войдите в opencode и
привяжите ПК по коду из панели сервера.

**Сервер.** Распакуйте архив, задайте переменные окружения и запустите
`./OpenCodeSpend.Web`, затем поставьте за reverse-proxy.

```bash
Spend__Mode=server
Spend__DatabasePath=/opt/opencodespend/data/spend.db
Spend__TimeZone=UTC
Spend__PairingTtlMinutes=5
# при необходимости:
# Spend__GoogleClientId / Spend__GoogleClientSecret
# Spend__GitHubClientId / Spend__GitHubClientSecret
```

```bash
./OpenCodeSpend.Web
```

### ✨ Основное

- Лимиты Go — окна 5 часов / неделя / месяц с прогрессом.
- Траты по дням и разбивка по моделям.
- Платежи и статус подписки.
- Живые сессии с фазами и остановкой агентов.
- Мультиаккаунт — несколько аккаунтов на одном сервере.
- Мгновенные обновления через SSE — без перезагрузки страницы.
